# AN AI Relight V4 — Creative Relight

Standalone Lightroom Classic batch relighting plug-in.

V4 combines:
- MODNet Photographic human matting
- Depth Anything V2 Small monocular depth
- Depth-aware subject + scene relighting
- Background mood and color temperature control
- Light spill, subject separation, shadow shaping
- Creative contrast, bloom, vignette and color finish
- Full Auto, Preset Based and Manual Creative modes
- Color-managed TIFF output and Lightroom auto-import/stack

The plug-in is offline after installation and does not modify AN AI Edit.
